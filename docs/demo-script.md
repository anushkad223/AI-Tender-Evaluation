# 3-minute SIH demo script

1. **Problem:** Procurement officers receive multiple unstructured tender and bidder documents. Manual requirement-by-requirement checking is slow and error-prone.
2. **Upload:** Open New Evaluation. Upload one tender and two bidder submissions.
3. **Extraction:** Explain that the backend extracts text and identifies requirement objects.
4. **Verification:** Open Bid Evaluation. Each requirement shows status, risk, confidence and the exact supporting evidence.
5. **Comparison:** Select another bidder. Show that the same rules are applied consistently and that gaps are highlighted.
6. **Human-in-loop:** Click Accept/Reject/Review. Explain that AI does not make the final procurement decision; the officer does.
7. **Audit:** Every officer action is stored in the audit table.
8. **Report:** Download the CSV report as an audit-ready evaluation artifact.

### Key line

“Nishtha does not replace the procurement officer. It turns scattered documents into evidence-backed, traceable findings so the officer can make a faster and more consistent decision.”
